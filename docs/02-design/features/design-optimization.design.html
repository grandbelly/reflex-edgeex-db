2. 핵심 — 테마 메커니즘 (검증됨)

실증 경로(컴파일된 .web 출력 인용): .web/app/root.jsx:52 <ThemeProvider attribute="class"> + .web/components/reflex/radix_themes_color_mode_provider.js. 즉 Reflex는 <html class="dark"> 를 emit하며 [data-theme] 가 아님 — 설계의 모든 다크 스코프는 .dark 로 정정.

2.1 동작 원리

  1. Pre-hydration: next-themes가 localStorage('theme') 읽어 하이드레이션 전 <html class="light|dark"> 동기 설정 → FOUC 없음(빌트인).
  2. Radix 재스코핑: radix_themes_color_mode_provider.js 의 useEffect가 .radix-themes[data-is-root-theme] 의 class를 remove('light','dark')+add(resolved). 이 class가 Radix 색스케일을 뒤집어 rx.color("teal",9)→var(--teal-9) 254개가 자동 전환(별도 토큰 치환 불필요).
  3. 커스텀 표면: --am-* 를 동일 .dark 스코프에 묶어 Radix와 같은 타이밍에 flip.
  4. 토글: toggleColorMode() → setTheme() → next-themes가 localStorage 영속 + html class 갱신.

2.2 핵심 API

# ksys_app.py — 정적 핀 해제 (네이티브에 class 토글 위임)
rx.theme(appearance="inherit")          # was appearance="dark"

# 헤더 토글 (OQ2 사용자 노출)
rx.color_mode.button()                  # 네이티브 sun/moon
# 대안: from reflex.style import toggle_color_mode; rx.icon_button(on_click=toggle_color_mode)

# per-mode 자산 스왑(로고/이미지 등 CSS 변수로 못 덮는 것만)
rx.color_mode_cond(light=..., dark=...)

# 기존 254 rx.color 호출은 유지 — class 토글로 자동 듀얼
# 신규 코드: 표면색은 var(--am-*), 의미색만 rx.color 허용

7. SCADA + 라이트 커버리지 (OQ1)

SCADA 화면의 실제 수선 표면은 SVG 하드코딩 hex 뿐 — rx.color 부분은 네이티브 class 토글로 공짜 전환. 컨테이너→am_card, 텍스트→--am-text/--am-muted, 심각도→am_badge(--ks-alarm/amber/aqua→--am-error/warning/success 의미 매핑). 시그니처 아쿠아(--ks-aqua)는 .dark에서만 보존, 라이트는 --am-accent(#0066cc)로 치환해 라이트 WCAG 대비 확보. 양테마 스크린샷으로 라이트(흰 배경 위 라인/노드 대비)·다크(계기판 정체성 무회귀) 검증.
