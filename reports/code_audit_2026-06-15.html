트랜잭션 오염 (systemic)get_async_session()이 한 트랜잭션을 다중쿼리에 공유 → 1개 실패가 형제쿼리 전부 롤백. 거의 모든 핸들러에 반복대시보드 마비의 구조적 원인
broad except 은폐전 계층 except Exception: return [] + 일부 print() → 위 크래시들이 "빈 패널"로 surface, 진단 불가버그가 지금껏 안 보인 이유
