④ 알려진 이슈 (후속)

이슈1 — COPY 백필이 continuous aggregate에 materialize 안 됨. COND_003 원본 1460행(백필+라이브) 중 agg_1m엔 라이브 8버킷만, 백필 1440점 누락. 압축청크 아님(0 compressed). refresh_continuous_aggregate(force=>true)도 COPY 데이터 미반영 — TimescaleDB COPY+cagg invalidation 엣지케이스. → 트렌드 히스토리 막힘. 대안: 백필을 정상 INSERT 경로로 or cagg 재생성.
이슈2 — ai_knowledge_base 테이블 누락. 코드는 SELECT/INSERT만, DDL 없음. 단 풀백업 덤프(ecoanp_full_backup_20251019.dump)에 정의 존재 → 추출/복원 가능. /ai RAG 실응답에 필요.
이슈3 — influx_latest VIEW @100태그 통계쿼리 204ms (5태그 6ms, 초선형). 매 10초 호출. 010이 influx_latest를 influx_hist DISTINCT ON 스캔 뷰로 재정의 → 스케일서 비용. Layer 3 최적화 타깃 (기능검증 후). 참고: influx_latest_old 하이퍼테이블 존재 = 과거 materialized latest 가능성.

⑤ 종합 판정

전체 앱 기능: 핵심 도메인(대시보드·알람·예측·통신·태그뷰) 정상 동작 확인. ML(model-performance/training)은 셸 정상이나 훈련 데이터 부재로 빈상태. 트렌드는 cagg 백필 이슈로 히스토리 막힘. AI는 RAG 백엔드(ai_knowledge_base) 미완. 대시보드 마비라는 치명결함을 기능검증으로 발견·복구한 것이 최대 성과 — 최적화는 이 기반 위에서.
