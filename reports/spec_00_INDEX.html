핵심 데이터 흐름 2개 (DB spec §6)

[Forecast loop — 10분 주기]
  ForecastScheduler @ x:00
    → model_registry.model_pickle BYTEA load
    → ThreadPoolExecutor 45s timeout → model.predict()
    → INSERT predictions (N rows for N horizons)
    → INSERT forecast_player_cache (1 snapshot)
  ActualValueUpdater @ x:01 (10분 주기)
    → UPDATE predictions SET actual_value = ... WHERE target_time < NOW()
  PerformanceAggregator @ x:03 (1시간 주기)
    → INSERT prediction_performance

[Alarm loop — 10s 주기 + NOTIFY/LISTEN]
  AlarmMonitor (every 10s)
    → SELECT influx_hist (최근 데이터)
    → evaluate vs influx_qc_rule thresholds (5분 dedup)
    → INSERT alarm_history
    → pg_notify('alarm_event', event_id)        ← 1da09aa + a5a530f fix
    → DatabaseEventListener (psycopg3 LISTEN)    ← db_events.py channel validator
    → frontend WS update (real-time alarm 카드)
