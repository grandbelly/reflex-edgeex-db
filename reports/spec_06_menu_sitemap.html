3.5 Query String 사용 현황

현재 모든 페이지는 query string 미사용. 서브 상태(예: Alarms active/history 탭)는 클라이언트 State 변수(AlarmsState.view_mode)로 관리됨.

권고: /alarms?view=history 패턴이 딥링크 공유에 유리하나, Reflex 라우팅 특성상 URL query param과 State 동기화에 별도 구현 필요. 현행 State-only 방식은 유지 가능하나, 알람 이력 딥링크 공유가 필요할 경우 /?tab=history 패턴 검토.

4. 네비게이션 흐름

4.1 사이드바 / Shell 구조

현재 활성 Shell: layout.py → shell() 함수. layout_v2.py는 미사용 (어떤 페이지도 shell_v2 또는 responsive_shell을 import하지 않음).

shell(content, active_route)
  ├── 조건부 사이드바
  │     ├── B.sidebar_collapsed == True  → collapsed_sidebar() (64px, 아이콘만)
  │     └── B.sidebar_collapsed == False → sidebar(active_route) (240px, 전체)
  │           ├── 상단 로고 섹션 (KSYS 이미지 + toggle 버튼)
  │           ├── 네비게이션 메뉴 (ACTIVE_MENU 순환 렌더링)
  │           └── rx.spacer()
  └── 메인 콘텐츠 영역
        └── children (페이지 본문)

사이드바 토글: - B.toggle_sidebar → BaseState.sidebar_collapsed 불리언 반전 - 상태는 세션 범위, 새로고침 시 초기화 (퍼시스턴트 스토리지 미사용) - 사이드바 기본 상태: 열림 (collapsed=False)

Collapsed 사이드바 크기: width: 64px — 아이콘만 표시, 툴팁 없음 (UX 개선 여지)

CSS 클래스: hidden lg:flex — lg 미만(768px↓) 화면에서는 사이드바 완전히 숨겨짐. 모바일에서 대체 네비게이션 없음. (§7 참조)

4.4 Breadcrumb 사용 여부

breadcrumb 미사용. 모든 페이지에 현재 위치 표시용 breadcrumb 없음. 사이드바의 active 항목(border-left 파란색)이 유일한 현재 위치 표시 수단.

4.5 Browser 뒤로가기 동작

Reflex의 SPA(Single Page App) 라우팅 특성상 브라우저 뒤로가기는 정상 동작. 단, 위자드 Step 이동은 URL 변경 없이 State로만 관리되어 뒤로가기로 Step을 되돌릴 수 없음.

7. 모바일/반응형 대응 추정

7.1 현재 구현 분석

layout.py shell() 함수 CSS 클래스:

# 사이드바 (expanded)
class_name="hidden lg:flex flex-col"

# 사이드바 (collapsed)  
class_name="hidden lg:flex flex-col"

hidden lg:flex = lg 미만(< 1024px) 화면에서 사이드바 완전 숨김. 이때 대체 네비게이션(모바일 햄버거 메뉴, 하단 탭바 등)이 없음.

결론: 모바일 (< 1024px) 에서 KSYS는 사실상 사용 불가능한 상태. 사이드바가 사라지고 대체 네비게이션이 없으므로 페이지 간 이동 수단이 없음.

부록 B — 라우트 등록 방식 메모

KSYS는 Reflex의 decorator-based page registration 사용: - 각 페이지 모듈이 @rx.page(route="...", title="...") 데코레이터 보유 - ksys_app.py에서 from .pages import module_name import 시 데코레이터가 실행되어 라우트 등록 - app.add_page() 호출 없음 — import만으로 등록되는 구조 - 따라서 import 누락 = 라우트 없음 = 404 (P-15, P-16 사례)

이 구조에서 dead page 탐지는 ksys_app.py import 섹션과 pages/ 디렉토리 파일 목록 비교로 즉시 가능.
