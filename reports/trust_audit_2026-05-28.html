판정 기호

  • TRUE: diff가 commit message와 일치 + runtime 작동 확인
  • PARTIAL: diff는 일치하지만 runtime 검증 일부만 함
  • OVERSTATED: diff는 일치, runtime 미검증 / 메트릭 미측정
  • FALSE: commit message 주장이 diff와 다름 (예: complete fix 라 했는데 partial)

검증 단계

  • (a) 읽기/수정 없는 작업
  • (b) py_compile / bash -n 만 (syntax)
  • (c) import test / docker boot / route 200 (runtime existence)
  • (d) 실제 시나리오 실행 (예: UI 클릭으로 acknowledge_alarm 호출, save_model 학습 후 저장)
  • (e) syntax only, target 환경 (RPI) 미실행
